# Zvuky

Nahrané pusou. Každý soubor je krátký `.mp3` (do 0,5 s). Když některý chybí, je prostě ticho.

| soubor | kdy zní | jak ho udělat pusou |
|---|---|---|
| `klik.mp3` | klik na štítek nebo odkaz | cvaknutí jazykem, „tk“ |
| `sust.mp3` | listování fotek, přepnutí přepis/rukopis | krátké „šššt“ |
| `plesk.mp3` | otevření textu nebo fotky, přilepení | „pop“ nebo „plk“ rty |
| `fuk.mp3` | zavření fotky | krátké foukání „ffff“ |
| `bzz.mp3` | jednou za návštěvu, první kliknutí na webu | kopírka, „bzzzzt-tk“ |
